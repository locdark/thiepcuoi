Đường Dẫn Cơ Sở Dữ Liệu (Cloud Database Endpoint)

💡 Hỗ trợ trực tiếp Firebase Realtime Database (Miễn phí vĩnh viễn, không giới hạn request/ngày) hoặc bất kỳ REST API JSON nào.

Hướng Dẫn Tạo Firebase Database Miễn Phí (1 Phút)

1

Truy cập console.firebase.google.com và đăng nhập bằng tài khoản Gmail.

2

Bấm "Thêm dự án" (Add project), đặt tên bất kỳ (VD: thiepcuoi) và nhấn Tiếp tục.

3

Ở menu trái, chọn Build > Realtime Database > Bấm Tạo cơ sở dữ liệu. Chọn vị trí (Singapore/Mỹ) và chọn chế độ Test mode (Thử nghiệm).

4

Sao chép đường link ở đầu trang (dạng https://...firebasedatabase.app), dán vào ô URL Database ở trên và bấm "Lưu URL"!

Sao Lưu & Phục Hồi Dữ Liệu Dự Phòng (JSON)

Tải về toàn bộ danh sách khách mời, lịch sử đọc thiệp, lời chúc mừng và cấu hình STK / Lễ cưới về máy để lưu trữ hoặc chuyển đổi giữa các thiết bị dễ dàng.
